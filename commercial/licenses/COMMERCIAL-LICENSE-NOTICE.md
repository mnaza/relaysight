# Commercial edition notice

The `commercial/` tree is intentionally separated from the Community Core and is intended for a proprietary commercial license.

This prototype includes the boundary and a minimal entitlement service so the combined development tree can be exercised end-to-end. Before a public release, move `commercial/` to a private repository or private package registry and replace this notice with the final commercial EULA/license drafted for the business.

Plugins are **not** a commercial-only feature. The plugin SDK, registry and AI/storage contracts live in the Community Core and remain available in both editions.
