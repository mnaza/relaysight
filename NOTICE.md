# Licensing split

## Community Core

Everything in this repository **except `commercial/`** is currently intended to be released under **GPL-3.0** for the open-source self-hosted edition.

The plugin SDK/runtime are part of Community Core. AI and storage plugins are deliberately not gated by a commercial license.

## Commercial edition

The `commercial/` directory is a development-time overlay and is **not** covered by the Community license. It is intended to be distributed under a separate proprietary commercial agreement. See `commercial/licenses/COMMERCIAL-LICENSE-NOTICE.md`.

Before public launch, have counsel confirm the final license split. If protection against third parties offering modified hosted versions without publishing changes is important, evaluate AGPL-3.0 for Community Core before accepting outside contributions.
